**Ripe Mango, Glistening.** One ingredient, close up: half a perfectly ripe mango, its orange flesh glistening with juice, on dark slate in soft window light. Nothing else competes for the eye — just the mango, at its most mouth-watering.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only, no network) validates the bundled photograph in `assets/entry.jpg` — whole JPEG, within 1024×1024 px and 1 MiB — and writes it to `$MAKEFUN_OUTPUT_DIR/entry.png` (default `/output/entry.png`).
